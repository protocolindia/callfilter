BUILD INSTRUCTIONS
============================================================

OPTION A — Android Studio (recommended)
---------------------------------------
1. Unzip this archive into a folder, e.g.  D:\callfilter-playstore-v25
2. Open Android Studio → File → Open → select that folder
3. Wait for Gradle sync (Android Studio will auto-generate gradle-wrapper.jar)
4. Place your keystore at  D:\callfilter-playstore-v25\keystore\release.keystore
5. Place your  D:\callfilter-playstore-v25\keystore\keystore.properties  containing:

        storePassword=your-password
        keyAlias=your-alias
        keyPassword=your-password

6. Build → Generate Signed Bundle / APK → APK → release
   Output goes to:  app\build\outputs\apk\release\app-release.apk

OPTION B — Command line (Windows PowerShell)
--------------------------------------------
Prerequisite: this only works if you have gradle-wrapper.jar.
If you've built earlier versions of this project, COPY THE FILES BELOW
from your old project into this new one:

   gradle\wrapper\gradle-wrapper.jar
   gradlew
   gradlew.bat

Then:
   cd D:\callfilter-playstore-v25
   .\gradlew.bat clean
   .\gradlew.bat assembleRelease

If you don't have those files and want to skip Android Studio:
   1. Install Gradle 8.7 manually (https://gradle.org/install/)
   2. cd D:\callfilter-playstore-v25
   3. gradle wrapper --gradle-version 8.7
   4. .\gradlew.bat assembleRelease
